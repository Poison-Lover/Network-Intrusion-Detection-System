# Network-Intrusion-Detection-System
MACHINE LEARNING BASED NETWORK INTRUSION DETECTION SYSTEM

Project Report

⸻

Abstract

With the rapid growth of internet-based communication systems, cybersecurity threats have become increasingly advanced and difficult to detect using traditional rule-based security systems. Conventional intrusion detection systems depend mainly on predefined attack signatures, making them ineffective against new and unknown attacks. This project presents a Machine Learning Based Network Intrusion Detection System (NIDS) capable of detecting suspicious network behavior using anomaly detection techniques.

The proposed system uses the NSL-KDD dataset to train a Random Forest Machine Learning model capable of classifying network traffic into normal and malicious categories. The project aims to provide a lightweight, scalable, and intelligent intrusion detection mechanism that can identify attacks such as Denial of Service (DoS), Probe attacks, Remote to Local (R2L), and User to Root (U2R).

The system is developed using Python, Flask, Pandas, NumPy, and Scikit-learn. The backend performs preprocessing, feature engineering, model training, prediction, and evaluation, while the frontend dashboard visualizes threat analysis results. The project demonstrates how Machine Learning can improve network security systems by enabling dynamic attack detection instead of relying solely on static signatures.

1. Introduction

Cybersecurity has become one of the most important aspects of modern computing systems. Organizations, educational institutions, government agencies, and businesses depend heavily on computer networks for communication and data transfer. As the use of networks increases, cyberattacks have also become more sophisticated and dangerous.

Intrusion Detection Systems (IDS) are security tools designed to monitor network traffic and identify suspicious activities. Traditional IDS solutions are mostly signature-based, meaning they compare incoming traffic against a database of known attack signatures. While effective against previously known attacks, these systems struggle to detect new and evolving threats.

Machine Learning offers a modern solution to this challenge. By learning patterns from historical network data, Machine Learning models can identify unusual behavior and classify it as malicious or normal. This project focuses on developing a Machine Learning Based Network Intrusion Detection System capable of intelligently analyzing traffic patterns and detecting cyber threats.

The system uses the Random Forest algorithm trained on the NSL-KDD dataset. The trained model is integrated with a Flask backend and a modern cybersecurity dashboard to provide an interactive and intelligent threat analysis platform.

2. Problem Statement

Traditional network intrusion detection systems rely heavily on static attack signatures. These systems are unable to efficiently detect new, modified, or unknown attacks. As attackers constantly evolve their techniques, traditional systems become less effective.

Another challenge is the high rate of false positives and false negatives generated by many security systems. Excessive false alarms reduce the efficiency of network administrators and can lead to important threats being ignored.

The problem addressed in this project is the development of an intelligent intrusion detection system capable of:

* Detecting malicious network activity dynamically
* Identifying multiple attack categories
* Reducing false positives
* Supporting future scalability and integration
* Providing real-time analysis capability

10. Dataset Description

The project uses the NSL-KDD dataset, an improved version of the KDD Cup 99 dataset.

The dataset contains network traffic records labeled as normal or attack categories. It includes multiple features such as:

* Duration
* Protocol type
* Service type
* Source bytes
* Destination bytes
* Login attempts
* Error rates
* Connection counts

The dataset contains both normal traffic and attack records.

Attack categories include:

* DoS (Denial of Service)
* Probe
* R2L
* U2R

The NSL-KDD dataset is widely used for intrusion detection research because it removes duplicate and redundant records present in the original KDD Cup dataset.

13. Random Forest Algorithm

Random Forest is an ensemble Machine Learning algorithm.

It consists of multiple decision trees working together. Each tree independently predicts the output, and the final prediction is determined by majority voting.

Advantages of Random Forest:

* Handles large datasets efficiently
* Reduces overfitting
* Supports multiclass classification
* Works well with mixed feature types
* Provides high accuracy

Working Process:

1. Multiple decision trees are created.
2. Random subsets of data are selected.
3. Each tree makes predictions.
4. Majority voting determines the final output.

Precision

Measures how many actual attacks were correctly detected.

F1-Score

Balances precision and recall.

Confusion Matrix

Shows:

* True Positives
